எனது ஐடி / கடவுச்சொல் மாற்ற

தற்போதைய கடவுச்சொல்லை உறுதி செய்த பின், புதிய ஐடி/கடவுச்சொல்லை அமைக்கலாம். இரண்டையும் மாற்ற வேண்டியதில்லை — எதை மாற்ற வேண்டுமோ அதை மட்டும் நிரப்பவும்.

மொத்த ரிப்போர்ட்

இங்கே சேர்க்கும் நிர்வாகிக்கு தனி ஐடி & கடவுச்சொல் உருவாகும் — அதை அவருக்கு தனிப்பட்ட முறையில் (WhatsApp/நேரடி) தெரிவிக்கவும். அவர் தன் தொகுதியின் பிரச்சினைகளை மட்டுமே பார்க்க/நடவடிக்கை எடுக்க முடியும்.

நிர்வாகிகள் பட்டியல்

கிராம / வார்டு நிர்வாகி சேர்க்க

தொகுதி நிர்வாகிகள் தங்கள் தொகுதிக்குள் உள்ள கிராம/வார்டு நிர்வாகிகளை இங்கே சேர்க்கலாம். இவர்கள் தங்கள் தொகுதியின் பிரச்சினைகளை பார்க்க/நடவடிக்கை எடுக்க முடியும்; நிர்வாகிகள் அல்லது செய்தி மேலாண்மை இவர்களுக்கு தெரியாது.

கிராம / வார்டு நிர்வாகிகள் பட்டியல்

செய்தி / நிகழ்வு சேர்க்க

நீங்கள் புதிய செய்தி/நிகழ்வு சேர்க்கலாம். ஏற்கனவே வெளியிடப்பட்டவற்றை திருத்த/நீக்க தலைமை நிர்வாகம் அல்லது மாநில நிர்வாகியை தொடர்பு கொள்ளவும்.

வெளியிடப்பட்டவை

↑ ↓ பட்டன்கள் மூலம் வரிசையை மாற்றலாம் — இதுவே பொது பக்கத்தில் தெரியும் வரிசை (புதியது மேலே இல்லாத பட்சத்தில் கைமுறையாக நீங்கள் அமைத்தது).

பொது அமைப்புகள்

சூப்பர் அட்மின் ஐடி/கடவுச்சொல் மேலாண்மைக்கு 'நிர்வாகிகள்' tab-ஐ பார்க்கவும்.

Google Sheet + Drive உடன் இணைக்க வழிமுறை

1) script.google.com சென்று புதிய திட்டம் உருவாக்கவும். 2) கீழே உள்ள code-ஐ paste செய்யவும். 3) Deploy → Web App → Execute as "Me", Who has access "Anyone" செய்யவும். 4) முதல்முறை Deploy செய்யும்போது Drive/Sheet அனுமதி கேட்கும் — ஏற்றுக்கொள்ளவும். 5) கிடைக்கும் URL-ஐ மேலே பதிவு செய்யவும்.

பிரச்சினை பதிவின் போது இணைக்கப்படும் புகைப்படம்/PDF, இந்த script மூலம் "NTK Thoothukudi Uploads" என்ற Drive கோப்புறையில் தானாக சேமிக்கப்பட்டு, அந்த லிங்க் Sheet-லும் இந்த தளத்திலும் தோன்றும்.

தரவு காப்பு / மீட்பு

இந்த கருவியின் தரவு (பிரச்சினைகள், நிர்வாகிகள், செய்திகள்) அனைத்தும் இந்த சாதனத்தில் மட்டுமே சேமிக்கப்படுகிறது. JSON கோப்பாக பதிவிறக்கம் செய்து பாதுகாக்கவும்.
